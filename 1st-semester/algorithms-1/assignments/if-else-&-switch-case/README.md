# 📂 Activity List: Selection Structures & Math Logic

This directory contains a collection of 4 specific activities selected from the semester's curriculum. These problems focus on **quadratic equations**, **divisibility rules**, **categorical salary adjustments**, and **finding minimum values** in a data set.

---

## 📋 Activity Descriptions (Translated)

Below are the translated prompts for the algorithms found in this folder:

1.  **Quadratic Equation Roots:** Develop an algorithm to find the real roots of a quadratic equation in the form $Ax^2 + Bx + C = 0$.
2.  **Divisibility Check:** Create an algorithm in **Portugol** that reads a number and determines if it is simultaneously divisible by both **3** and **7**.
3.  **Categorized Salary Increase:** An employee's raise is determined by their specific category. Implement the following rules:
    * **Categories A, C, F, H:** 10% increase.
    * **Categories B, D, E, I, J, T:** 15% increase.
    * **Categories K, G:** 25% increase.
    * **Categories L, M, N, O, P, Q, R, S:** 35% increase.
    * **Categories U, V, X, Y, W, Z:** 50% increase.
4.  **Find Minimum Value:** Given a set of positive integers entered by the user, determine and print the **smallest value** in the set. The program should stop accepting data when the user enters `-1` (this value must not be included in the calculation).

---

## 📌 Project Context & Methodology
* **From Paper to Digital:** These activities were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some activities from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
