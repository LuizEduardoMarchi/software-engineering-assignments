# 📂 Exercise List: Repetition Structures (WHILE & REPEAT)

This directory contains a comprehensive set of exercises focused on **Loop Structures** (`enquanto` and `repita`) in Portugol. These tasks cover dynamic data entry, conditional termination (sentinel values), and mathematical simulations such as population growth and financial interest.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the assignments found in this folder:

1.  **Average of Positives:** Read numbers as long as they are positive and calculate the average of all entered values.
2.  **Range Counter (100-200):** Read numbers and count how many fall between 100 and 200. The program stops when **0** is entered.
3.  **Growth Simulation (Chico vs. Juca):** Chico is 1.50m (grows 2cm/year) and Juca is 1.10m (grows 3cm/year). Calculate how many years it takes for Juca to be taller than Chico.
4.  **Investment Yields:** Calculate monthly returns for bank clients based on investment types (Savings: 1.5%, Savings Plus: 2%, Fixed Income: 4%). Termination occurs when the client code is ≤ 0.
5.  **Triple Value:** Receive numbers and print the triple of each. Stop when **-999** is entered.
6.  **Positive Counter:** Read numbers while they are positive and display the total count of valid entries.
7.  **Cubes & Roots:** Read 4 numbers and display the cube and cube root for each.
8.  **Odd Numbers (0-20):** Display all odd integers within the range of 0 to 20.
9.  **Square of Numbers:** Read positive numbers and print their squares. The loop stops after processing the first number that is a **multiple of 6**.
10. **Population Growth:** Country A (5M inhabitants, 3% growth) vs. Country B (7M inhabitants, 2% growth). Calculate the years needed for A to surpass B.
11. **Positive Summation:** Sum multiple positive integers. The sequence ends when **-1** is entered (this value is not included in the sum).
12. **Minimum Value Search:** Identify the smallest value in a user-provided set of positive integers. Stop when **-1** is entered.

## 📌 Project Context & Methodology
* **From Paper to Digital:** These exercises were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**.This includes variable names (e.g., `soma`, `contador`), logic commands, and comments.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
