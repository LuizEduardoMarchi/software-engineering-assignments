# 📂 Exercise List: Advanced Vector (Array) Manipulation

This directory contains a comprehensive set of 10 exercises focused on **Vector (Array) structures** in Portugol. These tasks cover data storage, mathematical transformations, sorting algorithms, and statistical analysis of datasets.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the algorithms found in this folder:

1.  **Sequential Storage (0-50):** Store all integers from 0 to 50 in a vector and print all stored values.
2.  **Odd Numbers Filter (1-100):** Store all odd numbers within the closed interval of 1 to 100 in a vector and display them.
3.  **Multiples of Five (1-500):** Store all multiples of 5 within the closed interval of 1 to 500 in a vector and display them.
4.  **Halving Values:** Receive ten numbers from the user, store half of each value in a vector, and print the results.
5.  **Scalar Multiplication:** Read a vector `S[20]` and a variable `A`. Display the product of `A` by each element of the vector.
6.  **Ascending Sort:** Read a 10-position vector and display it sorted in ascending order.
7.  **Vector Normalization:** Read a 500-position vector and divide every element by the highest value found in the set. Display the resulting vector.
8.  **Vector Merging & Sorting:** Read two vectors of size 10. Create a third vector `S` of 20 positions containing all elements from both, sorted in ascending order.
9.  **Minimum Element Search:** Read a vector `N[20]`. Find the smallest element and its exact position, displaying: "The smallest element of N is M and its position is P."
10. **Temperature Statistics (1976 Data):** Process 121 days of temperature data (between 15ºC and 40ºC) to calculate and print:
    * The lowest and highest temperatures recorded.
    * The average temperature of the period.
    * The number of days where the temperature was below the average.

## 📌 Project Context & Methodology
* **From Paper to Digital:** These exercises were originally solved as handwritten tasks during lectures  and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
