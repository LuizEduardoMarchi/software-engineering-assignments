# 📂 Exercise List: Iteration Structures (FOR / PARA) - List 2

This directory contains the second set of exercises focused on the **PARA** (FOR) loop structure in Portugol. These activities involve mathematical sequences, exponential growth simulations (the Wheat and Chessboard problem), radioactive decay, and statistical data processing for groups of people.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the assignments found in this folder:

1.  **Multiplication Table:** Create an algorithm to calculate and display the multiplication table for any number provided by the user.
2.  **The Wheat and Chessboard Problem:** A monk asks to be paid in wheat grains placed on a 64-square chessboard. The first square gets 1 grain, and each subsequent square gets double the previous one. Calculate the total number of grains the monk received.
3.  **Radioactive Decay:** A radioactive material loses half of its mass every 50 seconds. Given an initial mass in grams, determine the time required for the mass to drop below 0.05 grams.
4.  **Range Filter (30-90):** Create an algorithm that receives 10 numbers and calculates how many are between 30 and 90.
5.  **Group Statistics (25 People):** Collect the age, height, and weight of 25 people and calculate:
    * The total number of people over 50 years old.
    * The average height of people aged between 10 and 20 years.
    * The percentage of people weighing less than 40kg among all analyzed.

## 📌 Project Context & Methodology
* **From Paper to Digital:** These exercises were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
