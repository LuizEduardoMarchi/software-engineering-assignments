# 📂 Exercise List: Iteration Structures (FOR / PARA)

This directory contains a comprehensive set of 10 exercises focused on the **PARA** (FOR) loop structure in Portugol. These tasks cover a range of logic challenges, from simple numeric sequences and mathematical filters to advanced series generation like Fibonacci and Ricci.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the assignments found in this folder:

1.  **Odd Numbers (0-20):** Display all odd integers within the range of 0 to 20.
2.  **Even Numbers Countdown (600-1):** Display all even numbers in descending order from 600 down to 1.
3.  **Multiples of Five (1-500):** Print all multiples of 5 within the closed interval of 1 to 500.
4.  **Square Root of Fifteen:** Receive fifteen numbers from the user and print the square root of each.
5.  **Min/Max Finder:** Read ten integers and identify the largest and smallest numbers in the list.
6.  **Even/Odd Counter:** Read 200 integers and count how many are even and how many are odd.
7.  **Factorial Calculation:** Calculate the factorial of a number `N` provided by the user.
8.  **Divisors of N:** Determine and display all divisors of a given number `N`.
9.  **Fibonacci Series:** Generate the Fibonacci sequence (1, 1, 2, 3, 5, 8...) up to the N-th term.
10. **Ricci Series:** Similar to Fibonacci, but the first two terms are provided by the user. Generate N terms and calculate their total sum (minimum 3 terms required).

## 📌 Project Context & Methodology
* **From Paper to Digital:** These exercises were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
