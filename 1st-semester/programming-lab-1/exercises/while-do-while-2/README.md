# 📂 Exercises: Iteration Structures (While / Do-While - List 02)

This repository contains the second set of exercises focused on iteration logic using `while` and `do-while` loops in C. These problems involve classic mathematical algorithms, number theory, and complex sequence generation.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific exercise folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

### 📝 Overview
This list addresses advanced algorithmic challenges:
* **Mathematical Algorithms:** Implementing the Euclidean Algorithm to find the Greatest Common Divisor (GCD) and calculating Factorials ($N!$).
* **Number Theory:** Verifying "Perfect Numbers" (sum of divisors equals the number) and "Prime Numbers".
* **Sequences & Series:** Generating the Fibonacci sequence for $N$ terms and creating conversion tables (Fahrenheit to Celsius).
* **Pattern Printing:** Developing nested loop logic to print specific numerical triangular patterns.
* **Optimization:** Finding the largest perfect square less than or equal to a given number $N$.

### 📋 Exercises Description

* **Exercise 01:** Identifies the largest number among ten integers provided by the user.
* **Exercise 02:** Calculates the factorial of a positive integer $N$ ($N!$).
* **Exercise 03:** Generates a temperature conversion table from 50 to 70 degrees Fahrenheit, with 1-degree intervals.
* **Exercise 04:** Verifies if a given positive integer is a "Perfect Number".
* **Exercise 05:** Checks whether a provided integer is a prime number.
* **Exercise 06:** Finds the largest perfect square that is less than or equal to a given number $N$.
* **Exercise 07:** Calculates and displays the Fibonacci sequence up to the $N^{th}$ term.
* **Exercise 08:** Implements the Euclidean Algorithm to calculate the Greatest Common Divisor (GCD) between two positive integers.
* **Exercise 09 & 10:** Programs designed to generate specific numerical patterns (triangular segments) using nested iteration.
* **Exercise 11:** An election tally system for three candidates. It processes votes for candidates (1, 2, 3), blank votes (4), and null votes (5) until the sentinel value (0) is entered. It calculates total counts and the percentage of blank/null votes relative to the total.
