# 📂 Exercises: Conditional Structures (If/Else - List 02)

This repository contains the second part of the exercise series focused on decision-making logic using `if` and `else` structures in C. These problems involve multiple conditions, range classifications, and mathematical comparisons.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific exercise folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

### 📝 Overview
This list focuses on more complex conditional logic, such as:
* **Academic Classification:** Grading students into "Approved", "Exame", or "Failed" based on specific thresholds, and calculating weighted averages to assign concepts (A to E).
* **Numerical Ordering:** Identifying the smallest or the intermediate value among three distinct integers.
* **Category Sorting:** Classifying individuals into categories based on age (e.g., sports categories for swimmers or health insurance tiers).
* **Weighted Calculations:** Using specific formulas for "Média de Aproveitamento" (MA) that include exercise averages and weighted exam scores.

> Some files in this directory were recently rewritten or created from scratch. These were originally missing or could not be completed during the regular college term; therefore, they have been updated to ensure the repository's integrity.

### 📋 Exercises Description

* **Exercise 01:** Reads four grades and classifies the student: Approved (>= 6.0), Exame (3.0 to 5.9), or Failed (< 3.0).
* **Exercise 02:** Determines and displays the smallest value among three distinct integers.
* **Exercise 03:** Identifies and displays the intermediate value between the smallest and the largest of three distinct numbers.
* **Exercise 04:** Classifies a swimmer into categories: Infantil A (5-7), Infantil B (8-10), Juvenil A (11-13), Juvenil B (14-17), or Adult (17+).
* **Exercise 05:** Determines the cost of a health insurance plan based on age ranges from R$ 30,00 up to R$ 250,00.
* **Exercise 06:** Calculates a student's weighted average (MA) using three exam grades and an exercise average (ME), then assigns a final concept (A, B, C, D, or E).
