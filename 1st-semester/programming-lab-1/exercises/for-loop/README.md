# 📂 Exercises: For Loop and Logic

This repository contains a specialized set of programming exercises focused on mathematical logic, sequence analysis, and optimization problems using C.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific exercise folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

### 📝 Overview
These exercises address advanced computational logic and mathematical properties:
* **Prime Numbers:** Identifying and summing prime integers within a given set.
* **Mathematical Properties:** Demonstrating the relationship between cubic numbers ($n³$) and the sum of consecutive odd numbers.
* **Sequence Analysis:** Determining the length of the maximum increasing segment within a numerical sequence.
* **Optimization:** Solving a packaging problem to find the minimum number of boxes required for shipping products while minimizing wasted space.

### 📋 Exercises Description

* **Exercise 01:** A program that calculates and displays the sum of prime numbers from a set of $N$ positive integers.
* **Exercise 02:** Given a value $M$, this program identifies and displays sets of consecutive odd numbers whose sums equal $n³$, for all $n$ from 1 to $M$.
* **Exercise 03:** A program that analyzes a sequence of $N$ integers to find and display the length of the longest strictly increasing segment.
* **Exercise 04:** A logistics optimization tool that calculates the minimum number of extra-large (50 units), large (20 units), medium (5 units), and small (1 unit) boxes needed to ship a given quantity of fragile products. The program processes a series of quantities until zero is entered.
