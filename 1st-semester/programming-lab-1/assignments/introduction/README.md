# 📂 Activity 01 - Programming Lab I

This repository contains the first set of laboratory exercises focused on basic programming logic, mathematical formulas, and sequential structures applied to real-world scenarios.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** `gcc (Rev8, Built by MSYS2 project) 15.2.0`
* **Language:** C (Source code uses Portuguese variables and comments)
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, `printf` strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific activity folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

---

### 📝 Overview
This activity covers fundamental computational logic, including:
* **Unit Conversion:** Days, months, and years to total days.
* **Geometry:** Volume calculations for cylindrical objects.
* **Commercial Logic:** Weight-based pricing and sales commission structures.
* **Financial Math:** Compound annual salary adjustments for a three-year period.

> [!IMPORTANT]
> Some files in this directory were recently rewritten or created from scratch. These were originally missing or could not be completed during the regular college term; therefore, they have been updated to ensure the repository's integrity.

---

### 📋 Exercises Description

* **Question 01:** A program that reads a person's age expressed in years, months, and days and displays it expressed only in days.
* **Question 02:** Calculation and presentation of the volume of an oil can using the formula: VOLUME = 3.14159 * RAIO² * ALTURA.
* **Question 03:** A program for a restaurant that charges R$ 60.00 per kilo; it reads the plate weight and shows the amount to be paid.
* **Question 04:** A soft drink factory ("Meia-Cola") sells products in 350 ml, 600 ml, and 2L formats. This program calculates total liters sold.
* **Question 05:** Calculation of a car salesman's final salary, including fixed base plus 5% commission on total sales.
* **Question 06:** A program that calculates a three-year salary projection with annual increments of 7%, 6%, and 5% applied cumulatively.
