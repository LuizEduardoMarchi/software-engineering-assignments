# 📂 Activity 02 - Programming Lab I

This repository contains the second set of laboratory exercises focused on conditional structures (if/else), logical comparisons, and decision-making flow.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** `gcc (Rev8, Built by MSYS2 project) 15.2.0`
* **Language:** C (Source code uses Portuguese variables and comments)
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, `printf` strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific activity folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number (e.g., `ex2.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

### 📝 Overview
This activity addresses intermediate programming logic, specifically focusing on conditional branches:
* **Financial Eligibility:** Determining loan approval based on income ratios.
* **Employee Compensation:** Applying differentiated percentage increases based on tenure.
* **Dynamic Pricing:** Calculating fuel discounts based on volume thresholds.
* **Inventory Management:** Implementing automated "reorder point" logic for stock control.

> [!IMPORTANT]
> Some files in this directory were recently rewritten or created from scratch. These were originally missing or could not be completed during the regular college term; therefore, they have been updated to ensure the repository's integrity.

---

### 📋 Exercises Description

* **Question 01:** A program that grants financing only if the requested amount is less than or equal to five times the user's salary.
* **Question 02:** Salary readjustment based on service time: less than 10 years (8% increase), otherwise (10% increase).
* **Question 03:** A gas station system (gasoline at R$ 5.40/L) with 4% discount for up to 20L and 6% for higher volumes.
* **Question 04:** Inventory control that calculates average stock and alerts "Efetuar compra" if current levels are below the average.
