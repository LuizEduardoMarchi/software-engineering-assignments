# 📂 Activity: Vectors (Arrays)

This repository contains laboratory exercises focused on the manipulation of vectors (one-dimensional arrays) in C, including data searching, filtering, and basic statistical analysis.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific activity folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

---

### 📝 Overview
This activity covers fundamental concepts of array handling, such as:
* **Data Selection:** Finding minimum and maximum values within a set.
* **Classification:** Counting elements based on specific criteria (e.g., age of majority).
* **Array Manipulation:** Reversing the order of elements within a vector.
* **Frequency Counting:** Identifying the number of occurrences of a specific value.
* **Math Logic:** Filtering and counting even numbers within a dataset.

### 📋 Exercises Description

* **Question 01:** A program that reads the weights of 10 people into a vector and identifies the lowest weight recorded.
* **Question 02:** A program that reads the ages of 10 people into a vector and counts how many are of legal age and how many are minors.
* **Question 03:** A program that reads 10 integers into a vector and displays them in reverse order.
* **Question 04:** A program that reads a vector of 10 integers and a specific value 'x', then calculates how many times 'x' appears in the vector.
* **Question 05:** A program that reads 10 integers into a vector and counts how many of those numbers are even.
* **Question 06:** A program that reads 10 random integers and determines the highest value stored in the vector.
