# 📂 Practical Activity 05: Line Follower Robot with EV3

This directory contains the project developed for **Practical Activity 05**, focusing on programming a LEGO EV3 robot to follow a black path using its Color Sensor, starting and stopping on red indicator lines.

---

## 📋 Activity Description (Translated)

Below is the translated prompt for the activity implemented in this folder:

* **EV3 Line Follower Logic:** Program a LEGO EV3 robot equipped with a **Color Sensor** to navigate a tracked path. The robot must:
  1. Start on the red line, which marks the starting point.
  2. Detect and continuously follow the black line along the track.
  3. Automatically stop upon detecting the red line at the end of the course.
  4. Constantly adjust its trajectory during movement to stay aligned with the black line.
  5. Display dynamic messages on the EV3 display or console indicating:
     * Start of the course.
     * Active black line-following state.
     * Detection of the end red line and complete stop.

## 🚀 How to Run

To open and execute this project, you will need **EV3 Classroom** (version **1.5.3** or higher).

1. Launch **EV3 Classroom** (v1.5.3+).
2. Go to `File` > `Open` (or `Arquivo` > `Abrir`) and select the project file (`.lmsp` or `.ev3p`).
3. Connect your EV3 Intelligent Brick via USB or Bluetooth.
4. Download and run the program on the EV3 Brick.
