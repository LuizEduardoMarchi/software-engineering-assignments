# 📂 Practical Activity 02: Back-and-Forth Robot with Touch Sensor

This directory contains the project developed for **Practical Activity 02**, focusing on programming a robot equipped with a Touch Sensor to navigate to the end of a table, detect contact, and return to its starting position.

---

## 📋 Activity Description (Translated)

Below is the translated prompt for the activity implemented in this folder:

* **Touch Sensor Back-and-Forth Logic:** Develop a program to control a robot equipped with a **Touch Sensor**. The robot must:
  1. Start at position 0 (start of the table).
  2. Move forward in a straight line until reaching the obstacle/boundary at the end of the table.
  3. When the Touch Sensor is triggered, reverse direction and move step by step back to the initial position.
  4. Upon arriving back at the starting position, stop or restart the movement cycle.

## 🚀 How to Run

To open and execute this project, you will need **EV3 Classroom** (version **1.5.3** or higher).

1. Launch **EV3 Classroom** (v1.5.3+).
2. Go to `File` > `Open` (or `Arquivo` > `Abrir`) and select the project file (`.lmsp` or `.ev3p`).
3. Connect your EV3 Intelligent Brick via USB or Bluetooth.
4. Download and run the program on the EV3 Brick.
