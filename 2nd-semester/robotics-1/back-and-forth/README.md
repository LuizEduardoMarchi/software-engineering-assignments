# 📂 Practical Activity 01: Creating a Back-and-Forth Robot

This directory contains the project developed for **Practical Activity 01**, focused on creating logic to control a robot that moves to the end of a table and returns to its starting point, repeating this movement cycle.

---

## 📋 Activity Description (Translated)

Below is the translated prompt for the activity implemented in this folder:

* **Back-and-Forth Robot Logic:** Develop the programming logic to control a robot moving on a table. The program simulates this movement by ensuring the robot:
  1. Starts at position 0 (start of the table).
  2. Moves forward step by step until reaching the maximum position defined by the user (end of the table).
  3. Upon reaching the end, reverses direction and moves backward step by step until returning to the initial position.
  4. Repeats this continuous movement cycle or executes it for a specified number of iterations.

## 🚀 How to Run

To open and execute this project, you will need **EV3 Classroom** (version **1.5.3** or higher).

1. Launch **EV3 Classroom** (v1.5.3+).
2. Go to `File` > `Open` (or `Arquivo` > `Abrir`) and select the project file (`.lmsp` or `.ev3p`).
3. Connect your EV3 Intelligent Brick via USB or Bluetooth.
4. Download and run the program on the EV3 Brick.
