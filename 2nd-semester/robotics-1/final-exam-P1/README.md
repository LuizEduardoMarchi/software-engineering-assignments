# 📂 Final Exam (P1): EV3 Line Follower with Obstacle Handling

This directory contains the project developed for **Exam P1**, focusing on programming a LEGO EV3 robot to follow a black track, handle physical obstacles, and manage navigation using color indicators for the start and finish lines.

---

## 📋 Activity Description (Translated)

Below is the translated prompt for the exam project implemented in this folder:

* **P1 Line Follower with Obstacle Pause:** Program a LEGO EV3 robot equipped with a **Color Sensor** (and obstacle detection sensor) to navigate a marked path. The robot must:
  1. Start on the red line marking the starting point.
  2. Detect and continuously follow the black line along the track, making dynamic trajectory adjustments.
  3. Upon encountering an obstacle along the path, pause for 5 seconds and then resume moving along the track.
  4. Automatically stop upon detecting the red line at the end of the course.
  5. Display dynamic messages on the EV3 display or console indicating:
     * Start of the course.
     * Active black line-following state.
     * Obstacle detection and temporary 5-second pause.
     * Detection of the end red line and final system shutdown.

## 🚀 How to Run

To open and execute this project, you will need **EV3 Classroom** (version **1.5.3** or higher).

1. Launch **EV3 Classroom** (v1.5.3+).
2. Go to `File` > `Open` (or `Arquivo` > `Abrir`) and select the project file (`.lmsp` or `.ev3p`).
3. Connect your EV3 Intelligent Brick via USB or Bluetooth.
4. Download and run the program on the EV3 Brick.
