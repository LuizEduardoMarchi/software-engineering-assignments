# 📂 Exercise List: Nested Conditional Structures (Nested IF / SE Aninhado)

This directory contains 10 advanced logic exercises focused on **Nested Conditionals** (`se-entao-senao` nested) in Portugol. These activities tackle complex decision-making processes, such as triangle classification, academic grading with recovery exams, payroll tax/bonus categories, and price table consultations based on multiple criteria.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the assignments found in this folder:

1.  **Triangle Classification:** Read three values (A, B, C) and check if they can form a triangle. If so, classify it as Equilateral, Isosceles, or Scalene.
2.  **Academic Average with Exam:** Calculate the annual average of four grades. If < 7, request a 5th grade (exam). Calculate the final average and report "Approved", "Approved with Exam", or "Failed".
3.  **Variable Salary Increase:** Update salaries based on job roles (Manager: 10%, Engineer: 20%, Technician: 30%). Any other role receives a 40% increase. Show old salary, new salary, and the difference.
4.  **Age Classification:** Classify a person as "Underage" (<18), "Legal Age" (≥18), or "Elderly" (≥65).
5.  **Swimming Categories:** Assign swimmers to categories based on age: Infantil A (5-7), Infantil B (8-10), Juvenil A (11-13), Juvenil B (14-17), or Senior (18+).
6.  **Travel Pricing:** Determine ticket prices based on destination (Northeast, North, Central-West, South) and whether it is a one-way or round-trip ticket.
7.  **Profit Margin Calculation:** Calculate sale prices based on purchase value, applying different profit percentages (30% to 70%).
8.  **Special Bank Credit:** Calculate a credit limit based on the average balance of the last year, applying percentages from 0% to 50%.
9.  **Month Identification:** Read a number (1-12) and print the corresponding month's name or an error message.
10. **Numeric Sorting:** Read three integers (A, B, C) and display them in ascending order.

## 📌 Project Context & Methodology
* **From Paper to Digital:** These activities were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
