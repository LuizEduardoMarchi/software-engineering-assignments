# 📂 Exercise List: Conditional Selection Structures (CASE / CASO)

This directory contains a set of exercises focused on the **ESCOLHA-CASO** (Switch-Case) selection structure in Portugol. These activities are designed to handle multiple conditional branches efficiently, covering scenarios such as calendar mapping, categorical data filtering, salary adjustments, and geometric calculations.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the assignments found in this folder:

1.  **Month of the Year:** Read a number representing a month (1-12) and print the month's name in full. If the input is outside this range, display an error message.
2.  **Parity and Range Filter:** Read a number. If it is even and less than 10, print "Even number less than Ten". If it is odd and less than 10, print "Odd number less than Ten". Otherwise, print "Number out of range".
3.  **Categorized Salary Increase:** Apply salary raises based on specific employee categories:
    * **Categories A, C, F, H:** 10% increase.
    * **Categories B, D, E, I, J, T:** 15% increase.
    * **Categories K, G:** 25% increase.
    * **Categories L, M, N, O, P, Q, R, S:** 35% increase.
    * **Categories U, V, X, Y, W, Z:** 50% increase.
4.  **Geometry Menu:** Provide a menu for the user to choose a calculation:
    * `1` – Area of a Triangle: `(base * height) / 2`
    * `2` – Area of a Rectangle: `side * side`
    * `3` – Volume of a Sphere: `(4/3) * PI * R³`

## 📌 Project Context & Methodology
* **From Paper to Digital:** These exercises were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
