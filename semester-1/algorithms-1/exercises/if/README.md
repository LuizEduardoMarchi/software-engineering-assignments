# 📂 Exercise List: Simple & Composite Conditional Structures (IF / SE)

This directory contains a collection of 11 foundational exercises focused on **Conditional Logic** (`se-entao-senao`) in Portugol. These activities cover basic comparisons, parity checks, divisibility rules, and multi-step arithmetic based on specific conditions.

---

## 📋 Exercise Descriptions (Translated)

Below are the translated prompts for the assignments found in this folder:

1.  **Greater or Less than 20:** Read a number and print whether it is greater than or less than 20.
2.  **Sum Threshold (10):** Read two integers and add them. If the result is > 10, display it; otherwise, print "Value less than 10".
3.  **Even or Odd:** Determine if a given integer `N` is EVEN (*PAR*) or ODD (*ÍMPAR*).
4.  **Positive or Negative:** Determine if a given number `N` is POSITIVE or NEGATIVE.
5.  **Conditional Summation:** Add two numbers. If the sum is > 20, add 8 to the result and display it. Otherwise, subtract 5 from the result and display it.
6.  **Roots vs. Powers:** Read a number. If it is positive or zero, print its square root. If it is negative, print its square.
7.  **Multiple of 3:** Determine and print if a number is a multiple of 3 or not.
8.  **Divisible by 5:** Inform the user if a given number is divisible by 5.
9.  **A Divisible by B:** Determine if number `A` is divisible by number `B` (both provided by the user).
10. **Min/Max of Two:** Read two numbers (`A` and `B`) and identify which is the smallest and which is the largest.
11. **Double Divisibility (3 and 7):** Check and inform if a number is simultaneously divisible by both 3 and 7.

## 📌 Project Context & Methodology
* **From Paper to Digital:** These exercises were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some exercises from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
