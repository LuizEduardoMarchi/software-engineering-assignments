# 📂 Activity List: Basic Physics & Geometry Calculations

This directory contains a set of activities focused on **sequential algorithms**, applying fundamental mathematical and physical formulas. These tasks involve unit conversion, volume calculation for geometric shapes, and time estimation.

---

## 📋 Activity Descriptions (Translated)

Below are the translated prompts for the algorithms found in this folder:

1.  **Metric Conversion:** Create an algorithm that reads a value in **meters** and converts it to **centimeters**.
2.  **Cube Volume:** Create an algorithm that reads the edge value of a cube and calculates its total volume.  
    * **Formula:** $\text{Volume} = \text{edge}^3$
3.  **Travel Time Estimation:** Create an algorithm that reads the distance to be traveled (in **km**) and the average speed of the vehicle (in **km/h**), then calculates the estimated travel time.  
    * **Formula:** $\text{Time} = \frac{\text{Distance}}{\text{Speed}}$
4.  **Cylinder Volume:** Create an algorithm that reads the base radius and the height of a cylinder to calculate its volume.  
    * **Formula:** $\text{Volume} = \pi \times \text{Radius}^2 \times \text{Height}$ (Using $\pi = 3.14$)

## 📌 Project Context & Methodology
* **From Paper to Digital:** These activities were originally solved as handwritten tasks during lectures and were converted into **Visualg** during the semester.
* **Missing Content:** Due to this manual conversion process, some activities from the original list may be missing from this repository.
* **Language:** While this documentation is in English, the source code (`.alg` files) is entirely in **Portuguese**. This includes variable names, logic commands, comments, and user interface messages.

## 🚀 How to Run
To execute these scripts, you must use **Visualg 3.0.7.0**.

1.  Open **Visualg 3.0.7.0**.
2.  Go to `Arquivo` > `Abrir` and select the desired `.alg` file.
3.  Press `F9` to run the algorithm.
