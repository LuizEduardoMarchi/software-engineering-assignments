# 📂 Activity: Repetition Structures

This repository contains laboratory exercises focused on repetition loops (`for`, `while`, `do-while`), iteration logic, and data accumulation in C.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** `gcc (Rev8, Built by MSYS2 project) 15.2.0`
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, `printf` strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific activity folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

---

### 📝 Overview
This activity covers various loop-based logic scenarios, including:
* **Data Filtering:** Counting specific occurrences within a set (e.g., height thresholds).
* **Dynamic Termination:** Processing input until a sentinel value (zero) is reached.
* **Mathematical Series:** Calculating sums based on specific patterns (even numbers).
* **Statistical Tracking:** Monitoring the frequency of different outcomes (dice rolls).

### 📋 Exercises Description

* **Question 01:** A program that reads the height of 10 people and calculates how many individuals are taller than 1.80m.
* **Question 02:** A program that reads multiple ages and identifies the highest age recorded. Execution stops when an age of zero is entered.
* **Question 03:** A program that reads a positive integer $n$ and calculates the sum of the first $n$ even numbers greater than zero.
* **Question 04:** A program that reads a list of numbers ending in zero and displays the total sum of all numbers in the list that are multiples of five.
* **Question 05:** A tracking system for 15 dice rolls that counts and displays the number of occurrences for each of the six faces.
