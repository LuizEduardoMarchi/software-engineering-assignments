# 📂 Exercises: Introduction to Programming Logic (List 01)

This repository contains the first set of exercises designed to introduce fundamental programming concepts in C, such as variable declaration, basic input/output, and arithmetic operations.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific exercise folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

### 📝 Overview
This introductory list addresses basic computational tasks and mathematical formulas, including:
* **Basic Arithmetic:** Operations for doubling, squaring, and summing numbers.
* **Unit Conversions:** Temperature conversion (Celsius/Fahrenheit) and time conversion (Seconds to H/M/S).
* **Geometry:** Calculating the area of a circle and electrical power requirements based on room dimensions.
* **Financial Logic:** Calculating restaurant bills with service fees and estimating painting costs based on area coverage.
* **Weighted Averages:** Computing academic grades with predefined weights (2, 3, and 5).

> [!IMPORTANT]
> Some files in this directory were recently rewritten or created from scratch. These were originally missing or could not be completed during the regular college term; therefore, they have been updated to ensure the repository's integrity.

### 📋 Exercises Description

* **Exercise 01 & 02:** Basic programs to calculate the double and the square of an integer.
* **Exercise 03 to 06:** Basic arithmetic operations including sum of squares, products, and averages of real numbers.
* **Exercise 07 & 08:** Implementation of temperature conversion formulas between Fahrenheit and Celsius.
* **Exercise 09:** Calculation of a circle's area using the formula: Area = π * R².
* **Exercise 10:** A restaurant billing system that adds a 10% waiter tip to the total.
* **Exercise 11 & 15:** Time manipulation exercises converting between total seconds and the HH:MM:SS format.
* **Exercise 12:** Calculation of a weighted average for three student grades.
* **Exercise 13:** A home improvement tool to calculate the number of lamps needed for a room (20W per m²).
* **Exercise 14:** A cost estimation tool for painting an area, calculating the number of 3.6L cans required and the total price.
