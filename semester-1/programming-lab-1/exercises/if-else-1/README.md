# 📂 Exercises: Conditional Structures (If/Else - List 01)

This repository contains a comprehensive list of exercises focused on decision-making logic using `if` and `else` structures in C. The problems cover basic comparisons, mathematical checks, and practical applications.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific exercise folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

---

### 📝 Overview
These exercises address various conditional logic scenarios, including:
* **Basic Comparisons:** Parity checks (even/odd), age of majority, and numeric equality.
* **Mathematical Verification:** Divisibility by 3, leap year identification, and multiple detection.
* **Academic & Personal Metrics:** Average calculation for grading and Ideal Weight calculation based on gender and height.
* **Labor Calculations:** Salary computation including overtime pay (50% additional for hours exceeding 40).

> [!IMPORTANT]
> Some files in this directory were recently rewritten or created from scratch. These were originally missing or could not be completed during the regular college term; therefore, they have been updated to ensure the repository's integrity.

### 📋 Exercises Description

* **Exercise 01:** Checks if a given integer is even or odd[cite: 160].
* **Exercise 02:** Determines if a person is of legal age based on their entered age.
* **Exercise 03:** Calculates the difference between two integers (larger minus smaller).
* **Exercise 04:** Compares two integers to determine if they are equal or different.
* **Exercise 05:** Verifies if a specific integer is divisible by 3.
* **Exercise 06:** Identifies if a given year is a leap year (multiple of 4).
* **Exercise 07:** Checks if one integer is a multiple of another[cite: 167].
* **Exercise 08:** Calculates the average of four grades and determines approval (minimum 6.0).
* **Exercise 09:** Compares two numbers; if different, it identifies the larger one.
* **Exercise 10:** Computes the ideal weight based on height and gender ('h' or 'm') using specific formulas.
* **Exercise 11:** Calculates a total salary based on hours worked and hourly rate, applying a 50% bonus for hours over 40.
