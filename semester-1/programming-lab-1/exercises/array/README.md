# 📂 Exercises: Arrays (Vectors)

This repository contains a specialized list of exercises focused on advanced array manipulation, including element swapping between different vectors, election data processing, and efficiency analysis of datasets.

---

### 💻 Environment and Setup
The exercises in this folder were developed and tested using the following configuration:
* **Compiler:** gcc (Rev8, Built by MSYS2 project) 15.2.0
* **Language:** C
* **Documentation:** English (README)
* **Source Code:** Portuguese (Variables, printf strings, and comments use Portuguese)
* **IDE:** Visual Studio Code (VS Code)

#### How to Run in VS Code:
1. **Open the Folder:** Open the specific exercise folder in VS Code.
2. **Terminal:** Open the integrated terminal (`Ctrl + '`).
3. **Compile:** Replace the `n` in `exn.c` with the exercise number you wish to compile (e.g., `ex1.c`):  
   `gcc exn.c -o program.exe`
4. **Execute:** Run the generated file:  
   `./program.exe`

---

### 📝 Overview
These exercises address complex logic involving one-dimensional arrays:
* **Vector Transformation:** Swapping elements between two distinct vectors (A and B) using inverse indexing logic.
* **Data Processing:** Simulating an election counting system for multiple candidates.
* **Efficiency Analysis:** Comparing different datasets to identify the most economical or efficient entry (e.g., fuel consumption).

> [!IMPORTANT]
> Some files in this directory were recently rewritten or created from scratch. These were originally missing or could not be completed during the regular college term; therefore, they have been updated to ensure the repository's integrity.

---

### 📋 Exercises Description

* **Exercise 01:** A program that fills two vectors (A and B) with 20 characters each and performs a symmetrical swap: the 1st element of A with the 20th of B, the 2nd of A with the 19th of B, and so on.
* **Exercise 02:** An election tally system that reads candidate codes and calculates total votes for each of the 10 candidates, identifying the winner. The input process terminates when a negative code is entered.
* **Exercise 03:** A vehicle efficiency analysis program that stores five car models and their respective fuel consumption. It identifies the most economical model and calculates the total fuel needed for each car to travel 1,000 kilometers.
